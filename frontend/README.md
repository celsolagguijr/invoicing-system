# Frontend - Quick Start

This is the React + Vite frontend of the invoicing system.

## Prerequisites

1. Node.js 18+
2. npm

## Install

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

By default, frontend runs on:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Important

Start backend first (`../backend`) so frontend API calls work correctly.
